IMPORTANT — extract the project completely:
1. Back up your existing Code On The Go TransVibe project, especially app/libs.
2. Extract this ZIP. It contains a single root folder named TransVibe.
3. Copy THE CONTENTS of that TransVibe folder into your CodeOnTheGoProjects/TransVibe folder.
   Don't end up with CodeOnTheGoProjects/TransVibe/TransVibe/app/src/main/res.
4. Verify: CodeOnTheGoProjects/TransVibe/app/src/main/res/values/strings.xml.
5. The AAR/JAR binary dependencies are not inside this ZIP. Keep your working
   external app/libs/ dependencies in the project. They are not language models.
   FFmpegKit: ffmpeg-kit-min-gpl-6.0-2.aar (or Free81 alternative)
   Sherpa: sherpa-onnx-1.13.5.aar
   ONNX Runtime only when not bundled with Sherpa
   Smart Exception from Maven Central or matching local JAR.
6. Delete ONLY build output directories app/build and build when appropriate.
   Keep app/libs, app/src/main/res, and all files used by the project.
7. In Code On The Go, run :app:assembleDebug.

Last reported error AAPT missing app_name/ic_launcher/themes/fonts was caused by
Android resources not available to its build. This ZIP contains those files;
we cannot confirm whether a future sync/build on your phone succeeds.

Warnings from llvm-strip in the phone's NDK tooling are independent of the
missing Android resources. They don't by themselves prove a build failure.
